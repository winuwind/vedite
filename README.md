# VEDITE - Offline Video Editor

Офлайн-редактор видео на Kotlin + Jetpack Compose.

## Стек
- Kotlin, Jetpack Compose
- Coroutines + Flow
- ViewModel + StateFlow (состояние UI)
- Room (локальное хранение проектов и параметров правки)
- Media3 Transformer (обрезка, изменение скорости, удаление аудиодорожки, экспорт)

## Основные пользовательские сценарии

### 1. Импорт и создание проекта
Пользователь выбирает видео из галереи. Создаётся проект, сохраняется в Room.

### 2. Обрезка
Пользователь задаёт начало и конец фрагмента на таймлайне. Предпросмотр показывает выбранный диапазон. Значения сохраняются в проект.

### 3. Изменение скорости
Пользователь выбирает видеоряд и коэффициент. Предпросмотр отражает изменение длительности.

### 4. Отключение звука
Переключатель «Без звука» исключает аудиодорожку выбранного видеоряда из результата.

### 5. Склейка видео
Пользователь выбирает видеоряд из галереи, и выбранный видеоряд добавляется в конец уже загруженного видеоряда.

### 6. Наложение звука
Пользователь выбирает аудио из файловой системы, выбирает фрагмент этого аудио и выбирает момент в видеоряде, на который будет наложено аудио. Новая аудиодорожка будет глушить прошлую в тех кадрах, в которых они накладываются.

### 7. Поворот
Пользователь выбирает фрагмент и выбирает угол поворота. Выбранный фрагмент будет повернут, видеоряд, по необходимости, будет дополнен черным фоном.

### 8. Сохранение и восстановление проекта
При выходе из экрана проекта все параметры сохраняются в Room. При повторном открытии проекта из списка все настройки восстанавливаются.

### 9. Экспорт
Пользователь запускает экспорт. В UI отображается прогресс, кнопка отмены. По завершении файл сохраняется в MediaStore, показывается сообщение об успехе.

### 10. Список проектов
Главный экран показывает сохранённые проекты с превью-миниатюрой и датой. Можно открыть проект, удалить его или создать новый.

## Критерии готовности (Definition of Done)

Приложение считается готовым, если выполняются пункты:

- [ ] Импорт видео из галереи работает, проект создаётся и сохраняется в Room.
- [ ] Обрезка: выбранный диапазон корректно применяется к результату экспорта.
- [ ] Изменение скорости: итоговый файл имеет ожидаемую длительность и воспроизводится.
- [ ] Отключение звука: в экспортированном файле отсутствует аудиодорожка.
- [ ] Параметры правки сохраняются между запусками приложения и восстанавливаются
      при открытии проекта.
- [ ] Экспорт показывает прогресс через StateFlow, поддерживает отмену и не блокирует UI.
- [ ] Экспортированный файл доступен в галерее устройства.
- [ ] Список проектов отображается, открывается и удаляется корректно.
- [ ] Приложение работает без доступа к сети.
- [ ] Нет падений при повторном открытии проекта, отмене экспорта и удалении проекта.

## Планируется после MVP (не блокирует готовность)
- Кадрирование кадра и поворот видео.
- Конвертация в другой контейнер/формат.
- Выбор кодека и битрейта при экспорте.
- Пакетная обработка нескольких клипов.
- Склейка видео.
- Наложение звука.

## Известные ограничения
- Поддерживаемые форматы входа ограничены возможностями Media3 Transformer.
